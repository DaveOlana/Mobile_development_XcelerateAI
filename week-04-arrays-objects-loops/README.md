## Use of Arrays

- Creating an array
  const myFirstArray[ "Array1", "Array2", "Array3", "Array4"];
  console.log(`I am printing my first set of arrays now with: ${myFirstArray[0]}`);

//An array can be placed and accessed inside another array - multidimensional array

- indexOf("Array1") can be used to find the index number of the specified array
  console.log(myFirstArray.indexOf("Array1"));

- unshift, push, and pop can be used to assign arrays to the first, next and remove array items in a list of arrays respectively.
  myFirstArray.unshift("myNewFirstArray")
  myFirstArray.push("TheLastArray")
  myFirstArray.pull("RemoveLastArray")
